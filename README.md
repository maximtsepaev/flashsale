# Flashsale

Flashsale - это веб-сервис для проведения быстрых распродаж с ограниченным временем и количеством товаров.
Проект ориентирован на магазины и команды, которым нужно запускать акционные продажи, отслеживать их статус и управлять предложениями в одном месте.

## Что это за проект

В текущей версии репозиторий не содержит основу проекта, после завершения работы над функционалом проект будет перенесен в ветку main.
Цель - собрать рабочую платформу для flash-sale сценариев: создание акций, публикация товаров и дальнейшее развитие пользовательской и административной части.

## Для кого

- для владельцев магазинов, которым нужен формат быстрых акций;
- для разработчиков, которые хотят дорабатывать и расширять платформу;
- для команд, которым важен понятный старт и единая точка входа в проект.

## Статус

Проект находится в активной разработке.
Разработка временно ведется в ветке `dev`.

## Ветки

- `main` - временно пустая, в будущем: стабильная точка входа и базовая документация;
- `dev` - основная рабочая ветка с текущими изменениями.

Если хотите смотреть свежий прогресс, используйте ветку `dev`.
