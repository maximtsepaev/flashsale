# Flashsale

Flashsale — это веб-сервис для проведения быстрых распродаж с ограниченным временем и количеством товаров.
Проект ориентирован на магазины и команды, которым нужно запускать акционные продажи, отслеживать их статус и управлять предложениями в одном месте.

## Что это за проект

В текущей версии проект находится в активной разработке в ветке `dev`.
Цель — собрать рабочую платформу для flash-sale сценариев: создание акций, публикация товаров, обработка заказов и дальнейшее развитие пользовательской и административной части.

## Для кого

- для владельцев магазинов, которым нужен формат быстрых акций;
- для разработчиков, которые хотят дорабатывать и расширять платформу;
- для команд, которым важен понятный старт и единая точка входа в проект.

## Логика работы

Платформа ориентирована на сценарий коротких распродаж:
- администратор создает акцию с ограничениями по времени и количеству;
- товары публикуются в рамках активной акции;
- пользователи оформляют покупку в период действия распродажи;
- система фиксирует статус акции и контролирует доступность товаров по условиям.

## Стек и фреймворки

### Используется в `dev` сейчас

**Язык и архитектура**
- Go 1.25.x — основной язык backend-части;
- микросервисный подход: `gateway`, `inventory`, `order` сервисы;
- HTTP + gRPC взаимодействие между сервисами.

**Backend и API**
- Gin (`github.com/gin-gonic/gin`) — HTTP-роутинг и API-слой в gateway;
- gRPC (`google.golang.org/grpc`) + Protobuf (`google.golang.org/protobuf`) — RPC-контракты и межсервисная коммуникация.

**Данные и доступ к БД**
- PostgreSQL 15 (Docker образ `postgres:15-alpine`) — основная реляционная база;
- `sqlx` (`github.com/jmoiron/sqlx`) — работа с SQL в Go;
- `lib/pq` (`github.com/lib/pq`) — PostgreSQL драйвер;
- SQL-миграции через `migrate/migrate` (запуск через Makefile).

**Очереди и события**
- Apache Kafka (Docker образ `confluentinc/cp-kafka:7.6.0`) — событийный обмен между сервисами;
- `segmentio/kafka-go` (`github.com/segmentio/kafka-go`) — producer/consumer в Go.

**Безопасность и авторизация**
- JWT (`github.com/golang-jwt/jwt/v5`) — токены аутентификации и авторизации.

**Инфраструктура и dev-окружение**
- Docker + Docker Compose — локальный подъем PostgreSQL, Kafka и сервисов;
- Makefile — команды для запуска сервисов и миграций;
- стандартный логгер Go `log/slog` — структурированное логирование.

### Планируется добавить в стек и фреймворки

- Redis через `go-redis` — кэширование и ускорение горячих операций;
- Dead Letter Queue (DLQ) — изоляция и обработка проблемных сообщений;
- Retry Policy — повторная обработка временно неуспешных операций;
- Idempotency-механизмы — защита от повторных операций в критичных сценариях;
- нагрузочное тестирование через `k6`;
- дальнейшее развитие отказоустойчивости, масштабируемости и наблюдаемости сервиса.

## Статус
